# 动态兴趣图谱外卖推荐 Demo

这个子 demo 用于展示报告里的核心思想：把用户历史订单和当前点击序列转成动态图谱信号，再用关系权重、时间衰减、标签稀有度和基础质量生成可解释 Top-K 商家推荐。

## 数据子集

页面内置 48 家中文外卖商家样本，覆盖川湘辣味、盖饭便当、轻食沙拉、炸鸡汉堡、烧烤夜宵、麻辣烫、粉面汤粥、甜品饮品、地方小吃、早餐粥点、日韩料理、东南亚料理、咖啡轻食、披萨意面、特色正餐等类型。每家商家都手动标注或归一化补全：

- 中文商家名、品类、菜系、商圈、代表菜品
- 口味、消费场景、价格区间、食材、做法、营养倾向
- 用餐时段、人群、份量、优惠、配送特征、服务特征
- 评分、月售、配送费、距离等基础排序特征

这些字段会被转成 16 类图谱关系，例如 `口味:麻辣`、`食材:牛肉`、`做法:现煮`、`营养:低脂`、`人群:健身人群`、`服务:辣度可选`。

## 展示逻辑

1. 初始状态：推荐列表随机探索，兴趣图谱为空，只显示用户节点。
2. 点击商家：系统把该商家的品类、菜系、口味、场景、商圈、价格、菜品、食材、做法、营养、人群等写入 `pref_click` 临时兴趣边。
3. 图谱展开：同时展示 `pref_hist` 历史订单时间衰减边和点击临时兴趣边。
4. 重新排序：全部 48 家候选商家按点击兴趣重合、历史兴趣重合、关系权重、标签 IDF、评分、月售、距离、配送费综合打分并整体刷新。
5. 推荐解释：推荐卡片和底部解释区展示 `用户 -> 点击/历史兴趣 -> 标签 -> 候选商家` 的可解释路径。

## 运行

从仓库根目录启动：

```bash
cd demo/takeout-kg
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```
